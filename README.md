# Math Quiz Game – C#

A console-based Math Quiz Game developed in C# to practice arithmetic operations and strengthen programming fundamentals.

## Features

- Generate random mathematical questions.
- Choose between 1 and 10 questions per quiz.
- Select a difficulty level: Easy, Medium, Hard, or Mixed.
- Practice addition, subtraction, multiplication, division, or mixed operations.
- Receive immediate feedback after each answer.
- Display correct and incorrect answer counts.
- View the final pass/fail result.
- Play multiple rounds.

## Technologies Used

- C#
- .NET Framework
- Visual Studio
- Console Application

## Programming Concepts

This project demonstrates:

- Functions and methods
- Loops and conditional statements
- Arrays
- Structures (`struct`)
- Enumerations (`enum`)
- Random number generation
- Basic input and output handling

## How to Run

1. Clone or download this repository.
2. Open `Project math game.sln` in Visual Studio.
3. Build and run the application.
4. Choose the number of questions, difficulty level, and operation type.
5. Answer the questions and review your final result.
